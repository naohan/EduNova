# EduNova — Frontend

App Next.js de EduNova (Hack4Edu Arequipa 2026).

La documentación del proyecto, **declaración de uso de IA**, licencia y autoría están en el [README raíz](../README.md).

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```
